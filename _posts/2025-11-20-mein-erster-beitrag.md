# Warum ich Markdown für Blogbeiträge nutze

Markdown ist **einfach** und **schnell** zu schreiben.
Ich kann mich auf den **Inhalt** konzentrieren, statt mich mit HTML-Tags zu beschäftigen.

## Vorteile
- **Lesbar**: Auch der Rohtext ist gut lesbar.
- **Portabel**: Läuft überall (GitHub, VS Code, etc.).
- **Flexibel**: Unterstützt Tabellen, Code, Bilder.

```markdown
| Syntax      | Beschreibung |
| ----------- | ----------- |
| `# Überschrift` | Große Überschrift |
| `*kursiv*`  | Kursiver Text |
```
